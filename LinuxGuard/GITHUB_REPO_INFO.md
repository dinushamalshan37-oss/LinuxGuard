**Quick upload instructions:**
1. Create a new public repository named `LinuxGuard` on github.com.
2. Extract `LinuxGuard_GitHub_Ready.zip`.
3. On GitHub, choose **Add file → Upload files**.
4. Upload **all files and folders inside `LinuxGuard`** (including `.github` if supported by your file picker); do **not** upload the ZIP as the code repository.
5. Commit the files. GitHub automatically displays `README.md` on your repository homepage.

To upload hidden files and directories more reliably, use the `git` commands near the bottom of `README.md` instead.
